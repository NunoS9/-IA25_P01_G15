# 🧠 IA25 – Projeto 01  
## Criação Automática de Horários Académicos com CSP

### 📘 Descrição do Projeto
Este projeto foi desenvolvido no âmbito da unidade curricular **Inteligência Artificial**,  
do **Instituto Politécnico do Cávado e do Ave (IPCA)**.  

O principal objetivo consiste em desenvolver um **agente inteligente** capaz de **criar e gerir horários de aulas de forma automática**,  
com base na abordagem de **Problema de Satisfação de Restrições (CSP)**.  
Para tal, é utilizada a linguagem **Python** e a biblioteca **`python-constraint`**, que permite modelar as variáveis,  
os domínios e as restrições associadas ao problema de horários académicos.

O projeto é implementado num **Jupyter Notebook**, integrando explicação teórica e prática,  
de forma a demonstrar todo o raciocínio, a formulação do problema e a execução do agente.

---

### 🧰 Tecnologias Utilizadas
- **Python 3.x** – Linguagem de programação principal.  
- **Jupyter Notebook** – Ambiente de desenvolvimento interativo.  
- **Biblioteca** [`python-constraint`].

### 📂 Estrutura do Projeto
- `IA_Project01.ipynb` → Notebook principal contendo:
  - Introdução e enquadramento teórico;
  - Formulação do problema como CSP;
  - Implementação do agente inteligente;
  - Análise dos resultados e conclusões.
- `README.md` → Ficheiro de documentação do projeto (este documento).  

---

### 🎯 Objetivos
- Modelar o problema da criação de horários como um **CSP**;  
- Aplicar **restrições hard e soft** de acordo com as regras académicas;  
- Utilizar heurísticas para **otimizar o processo de busca de soluções**;  
- Avaliar a eficiência do agente através de **resultados e métricas**;  
- Documentar todo o raciocínio e processo de desenvolvimento.
