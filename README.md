# -IA25_P01_G15
Este projeto foi desenvolvido no âmbito da unidade curricular de Inteligênca Artificial, do Instituto Politécnico do Cávado e do Ave. 
O objetivo é criar um agente inteligente, em que o mesmo seja capaz de gerar e gerir horários de aulas de forma automática, utilizando a abordagem de Problema de Satisfação de Restrições (CSP) e 
a biblioteca `python-constraint`.

# -Tecnologias utilizadas
- Python 3.x; 
- Jupyter Notebook;
- Biblioteca python-constraint`;
- Git & GitHub;
- CMD (linha de comandos).

# - Estrutura do projeto
- `IA_Project01.ipynb`: Notebook principal com toda a implementação (Markdown + Código); 
- `README.md`: Este ficheiro com descrição do projeto.
